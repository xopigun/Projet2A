# Projet 2A — Bus CAN, groupe 69

ENSEA 2A, projet « Conception d'une Électronique Modulaire (Bus CAN) ».
Auteurs (ordre alphabétique) : Samuel GOMRI, Dylan KIATI, Hugo MATHOUX.

**Où en est le projet : [banc-can/docs/ETAT_PROJET.md](banc-can/docs/ETAT_PROJET.md).**

| Dossier | Contenu |
|---|---|
| [`banc-can/`](banc-can/README.md) | Le banc de test : firmwares des nœuds, ICD, outils PC `canbench`, cartes KiCad (adaptateur USB-CAN, carte porteuse, câblage), simulation 3D, documentation |
| `Banc de Test/` | Dossier de définition du banc (source LaTeX et PDF) |
| `ICD/` | Formulaire ICD commun aux groupes partenaires |
| `Cobot/` | Schéma du bus CAN du Cobot |
| `GANTT/` | Planning détaillé (LaTeX) |
| `Management/` | Notes de pré-cadrage, RACI, registre des risques, plannings, macroplanning |
